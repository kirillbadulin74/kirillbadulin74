## Проекты

**[Vinoterra-TG-bot](https://github.com/kirillbadulin74/Vinoterra-TG-bot)** —
RAG-ассистент по вину в Telegram. Гибридный поиск (BM25 + векторный, слияние
через RRF) плюс добор соседних фрагментов раздела; своя база знаний на 2829
чанков. Схема поиска выбрана контролируемым экспериментом, а не по умолчанию:
прежний вариант «BM25 + ручной scope» давал Hit@1 1.000 на отработанных
вопросах и 0.625 на новых формулировках — то есть переобучался под уже
известные вопросы, поэтому ручной scope из прода убран. Генерация на OpenAI с
фоллбэком на DeepSeek; при недоступности API поиск деградирует до офлайнового
BM25 и бот продолжает отвечать. Оценки 👍/👎 пишутся в SQLite.

**[vino-terra-site](https://github.com/kirillbadulin74/vino-terra-site)** —
тот же RAG-движок в двух транспортах: FastAPI-эндпоинты для чат-виджета на
сайте и Telegram-бот, одно ядро на двоих. Развёрнуто на своём VPS: nginx,
systemd-юниты, инструкция деплоя. [Статическая версия сайта](https://kirillbadulin74.github.io/Vinoterra-site-html/)
без чата опубликована на GitHub Pages.

**[mini-crm](https://github.com/kirillbadulin74/mini-crm)** — учебная CRM
агентства недвижимости на чистом stdlib, ни одной pip-зависимости.
Telegram-бот дописывает события в JSONL-спул, импорт раскладывает их в SQLite
идемпотентно (детерминированный `source_key` под `UNIQUE` — спул можно
перечитать целиком в любой момент), веб-интерфейс читает базу read-only,
запись доступна только CSRF-защищённым действиям. Персональные данные
псевдонимизированы, обезличивание клиента — одна операция. 91 unit-тест.

**[exam-trainer](https://github.com/kirillbadulin74/exam-trainer)** —
CLI-тренажёр устных ответов: распознаёт речь локально через `faster-whisper`
(CUDA, с откатом на CPU), сверяет ответ с эталоном и разбирает его по пунктам
силами LLM. Нечёткий поиск билета по формулировке, потоковый вывод.
